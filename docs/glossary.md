# Glossary

| Term | Meaning |
|------|---------|
| PBN | Private Blog Network — several blogs that link to each other or to a money site. |
| Blogroll | List of outbound links in the sidebar, managed in admin. |
| On-page SEO | Per-post focus keyword, title, description, schema type, canonical, robots, OG image. |
| Bootstrap config | `config.php` values that only start the app (paths, timezone, debug). |
| Admin config | Settings stored in SQLite and edited in `/admin/settings.php`. |
| Template preset | One of 30 homepage looks: 5 layouts × 6 palettes, stored in settings. |
| Category | Topic grouping for posts, shown as colored badges. |
| Fail closed | On doubt or error, refuse the write or hide the content. |
